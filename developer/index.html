Quick commands

First time

  • git clone https://github.com/sebastvnd/cursorpie.gitGet the code
  • cargo tools hooks installTurn on the Git hooks, once per clone
  • cargo run --releaseTry the app

Before a pull request

  • cargo tools ci --quickOnly the checks that take seconds
  • cargo tools ciEvery check CI runs

Debug and plan

  • cargo tools infoFacts a bug report needs
  • cargo tools log reportLog report to paste into a bug report
  • cargo tools kanbanPrint the work board
