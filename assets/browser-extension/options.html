CursorPie Bridge

What the browser may do when CursorPie asks. Everything stays on this computer.

Groups of commands

Messages

Saved replies

Short texts for chat.template name (types it in the open chat) or chat.template name :: Chat (opens that chat first, like chat.send_to). Written as JSON, a name (letters, digits, - and _) and its text. In the text, {time} and {date} are filled in, and {name} and {first} (the first word) are the chat's name: the one written after ::, else the open chat's, which needs Allow reading messages. Example: {"omw": "On my way, back at {time}", "hi": "Hi {first}, I will call you later"}

Players

Notifications

All sites

The extension is allowed on the player sites, WhatsApp Web and Telegram Web only. To control the player of any other site (and to scroll any page) allow all sites; the extension still only acts when CursorPie asks.

Selector overrides (chats)

WhatsApp Web and Telegram Web change their pages without notice. If a chat command stops finding something, put a working CSS selector first here. Keys: rows, selected, unread, search, composer, send, header, scroll, messages (one message), text (the words inside it), incoming, outgoing (what says who wrote it), muted (a chat with notifications off), mention (an @mention badge), folders (the Telegram folder tabs). Example: {"whatsapp": {"composer": ["footer div[contenteditable]"]}}
